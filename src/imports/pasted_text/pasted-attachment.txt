# FIGMA MAKE — E2 PREMIUM ELECTRONICS & ACCESSORIES RETAIL TEMPLATE PROMPT

## ROLE

You are now acting as the **Figma Design Architect** for the Build It Factory template system.

The Master Role Prompt is the governing instruction.

You are **NOT designing a website for a specific client**.

You are creating the **Figma design reference for a reusable Build It Factory template** for premium consumer electronics and accessories retailers.

The design must be:

* reusable
* componentized
* responsive
* data-driven in structure
* client-neutral
* compatible with the Build It Factory workflow
* compatible with the existing Intake Form
* compatible with future Next.js / React implementation
* suitable for repeated client builds
* suitable for e-commerce implementation
* optimized for product discovery and conversion

Do not create client-specific branding.

Do not use Apple branding, Apple logos, Apple-specific UI, or Apple proprietary visual assets.

Apple is used only as **visual and UX inspiration** for:

* minimalism
* product-first storytelling
* large product imagery
* generous whitespace
* restrained typography
* clean navigation
* editorial product sections
* premium visual hierarchy
* simple conversion paths
* strong product CTAs

Do not copy Apple's website directly.

Do not reproduce Apple's exact layouts, typography, copy, colors, navigation structure, or proprietary visual identity.

The resulting template must work for multiple electronics retailers and technology brands.

# 1. DESIGN OBJECTIVE

Create a premium, production-ready **Consumer Electronics and Accessories e-commerce website template**.

The website should communicate:

* innovation
* technology
* quality
* reliability
* premium product selection
* modern lifestyle
* convenience
* trust
* product expertise
* seamless shopping

The visual direction should feel:

**Minimal + Premium + Modern + Editorial + Technology-Focused + Product-Centric**

The design should be inspired by the product-focused presentation of leading technology retailers while remaining completely brand-neutral.

Avoid:

* generic marketplace aesthetics
* cluttered e-commerce layouts
* excessive gradients
* excessive glassmorphism
* excessive rounded cards
* excessive shadows
* overly decorative interfaces
* dense product grids
* outdated electronics-store aesthetics
* aggressive promotional banners
* visually noisy discount badges
* excessive animations
* generic SaaS appearance

The website should feel like a **premium technology destination**, not a generic online marketplace.

# 2. CORE UX PRINCIPLE

The entire website should follow this hierarchy:

**Discover → Explore → Understand → Compare → Purchase**

Users should be able to:

1. Discover featured products
2. Browse product categories
3. Explore individual products
4. Understand product benefits
5. Compare relevant products
6. Select variants
7. Add products to cart
8. Complete checkout

The interface should minimize unnecessary friction.

Product imagery and product information should receive the highest visual priority.
